# 创赛 PPT 内容策划与路演检查清单

本清单综合模板附带的创赛制作指南，并补充了核验与交付检查。赛事规则优先级最高；模板说明和经验比例不应被当作统一评分标准。

## 一 先核对比赛要求

- [ ] 找到当届官方通知、评分表、答辩时长、页数限制、指定格式和必备声明。
- [ ] 确认参赛组别、赛道、评委关注点和材料提交时间。
- [ ] 按时长删减内容；不要因为模板页数多而把所有页面都放进演示稿。
- [ ] 准备一个更短的备用版本，并检查字体、视频、动画和电脑投影兼容性。

## 二 把项目材料改写成一条叙事

建议按评委理解项目的顺序组织，而不是按模板页码照搬：

1. **项目是什么**：一句话说明服务对象、解决的问题和产品/服务。
2. **为什么需要**：用可靠材料说明痛点、现有做法的缺口和目标客户。
3. **如何解决**：演示产品/服务、关键流程和使用场景。
4. **为什么可行**：解释技术或方法、创新点、知识产权、测试结果和差异化优势。
5. **如何持续**：说明客户获取、交付、合作资源、收入来源和主要成本。
6. **谁来完成**：用角色、具体经历和已完成工作证明团队能力。
7. **进展与下一步**：分阶段列出已完成成果、近期里程碑和所需资源。
8. **结果如何衡量**：给出财务假设、关键指标、风险和应对方案。

按本届评分表调整顺序；如果没有实际成果或数据，应直接说明当前阶段，不要编造。

## 三 页面表达

- 一页聚焦一个问题或一个结论；用短标题点明主题。
- 先保留结论和关键词，再用图表、流程图、产品图或证据支撑；细节放到口头讲解或备份页。
- 投影环境下检查标题与正文的大小、对比度、留白和阅读顺序。模板带有装饰元素时，若影响信息辨识就删减。
- 图表标出单位、时间范围、样本或口径、数据来源。避免没有来源的截图和无法解释的数字。
- 将专利、测试、奖项、合作和用户数据与证据材料一一对应。
- 预测值说明假设条件与计算逻辑，不能写成已实现结果。

## 四 现场讲述与问答

- [ ] 按规定时长完整计时至少一遍，留出开场、过渡和结尾时间。
- [ ] 讲稿与幻灯片、商业计划书、申报材料中的项目名称、数字和日期一致。
- [ ] 团队成员清楚各自负责范围，回答时先回应问题，再给出证据和解释。
- [ ] 预演市场、竞品、技术壁垒、客户验证、商业模式、现金流、风险和下一步计划。
- [ ] 对未知信息明确说明，不猜数据，不把计划说成已经完成。

## 五 文件交付前检查

- [ ] 删除模板里的旧姓名、学校、公司、产品、项目、品牌、联系方式和示例水印。
- [ ] 搜索“替换文本”“示例文本”“XXX”“某某”等占位词，并检查备注、母版和隐藏对象。
- [ ] 核对数字、币种、百分比、年份、单位、图表标签和数据来源。
- [ ] 在目标演示软件和实际电脑上通读并播放；检查缺字、溢出、动画顺序、音视频和字体替换。
- [ ] 只保留本次答辩需要的页面；备用页面单独放在末尾并标记。
- [ ] 确认模板、字体、图片和音乐的授权范围满足使用场景。

## 经验来源的边界

附带指南举例讨论了陈述、问答和团队表现的评分构成，并给出若干路演时长示例。这些数字来自模板随附材料，不能代表所有赛事。请用当届官方评分表和通知替换这些假设。
