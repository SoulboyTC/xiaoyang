# PPT 知识库

围绕 PPT 模板选择、内容策划和路演表达整理的中文知识库。首批资料来自两套绿色主题的农业科技与创新创业竞赛模板。

## 从这里开始

- [模板资源盘点与选择](docs/模板资源盘点与选择.md)：模板结构、页数、配色、适用场景与使用限制
- [低空农业绿色科技风模板分析](templates/低空农业绿色科技风.md)：页面特点、可借鉴做法和内容替换风险
- [深色创赛通用模板分析](templates/深色创赛通用绿色版.md)：三种绿色配色、动画版本与附加版式
- [创赛 PPT 内容策划与路演检查清单](guides/创赛PPT内容策划与路演检查清单.md)：从项目材料整理到现场答辩的实用检查项

## 使用原则

1. 把模板中的示例文案当作占位内容，不当作事实或行业数据。数字、奖项、专利、客户、市场规模和预测都要用项目自己的可核验材料替换。
2. 先按赛事官方通知核对组别、时长、评分项和必须内容，再决定页数与讲述顺序。模板自带的创赛指南只是经验参考。
3. 当前知识库只保存分析与方法总结，不分发原始 PPTX、字体、图片或模板预览。来源商品说明明确限定了学习交流用途；请先核对原始授权再用于商业项目或公开传播。
4. 保留每页数据来源、统计口径、日期和单位。无法核实的内容要标为假设，不能写成已取得的成果。

## 文件结构

```text
docs/       资源清单与选择建议
templates/  单套模板拆解

```

## 更新方式

新增模板时，先记录文件中实际可见页数和版本，再整理用途、内容结构、版式特征、字体依赖与授权范围。新增经验建议时，区分原始资料中的说法、赛事官方要求和本知识库的编辑建议。
